# Molu

Repositorio personal para organizar todas mis actividades: ingeniería de
telecomunicaciones (especialidad ferroviaria), clases de español para
rusohablantes, traducción, el máster en Sistemas Inteligentes (Salamanca) y
mi aprendizaje de Python.

## Estructura

| Carpeta | Contenido |
|---|---|
| [`telecomunicaciones/`](telecomunicaciones/README.md) | Notas y proyectos de ingeniería en telecomunicaciones, especialidad transporte ferroviario. |
| [`docencia-espanol/`](docencia-espanol/README.md) | Planificación y materiales de las clases de español para alumnos rusos. |
| [`traduccion/`](traduccion/README.md) | Encargos y proyectos de traducción. |
| [`python/`](python/README.md) | Ejercicios y proyectos mientras aprendo Python. |
| [`master-sistemas-inteligentes/`](master-sistemas-inteligentes/README.md) | Apuntes y trabajos del máster en Salamanca. |
| [`recursos-generales/`](recursos-generales/README.md) | Radar de herramientas de IA y notas sueltas que aún no encajan en ninguna otra carpeta. |

## Reglas básicas

- **Nombres de carpetas y archivos:** minúsculas, sin espacios ni tildes,
  separadas por guiones (`kebab-case`). Ejemplo: `clases-ruso-a1.md`.
- **Archivos pesados (audio/video):** no se suben a este repositorio, se
  guardan en Google Drive y aquí solo se deja el enlace. Ver
  `.gitignore` y `docencia-espanol/grabaciones/README.md`.
- **Commits:** mensajes cortos en imperativo describiendo qué se hizo,
  por ejemplo `Añade ejercicio de bucles en Python`.
- Cada carpeta principal tiene su propio `README.md` explicando su
  contenido y cómo está organizada por dentro.
