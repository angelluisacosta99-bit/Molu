# Búsqueda de empleo

Material de apoyo para la búsqueda de trabajo remoto junior de Angel: CV,
perfil profesional y seguimiento de candidaturas.

## Estructura

| Carpeta | Contenido |
|---|---|
| [`cv/`](cv/) | Datos base del perfil y borradores del CV. |

## Nota de privacidad

Los datos de contacto de terceros (profesores, supervisores de prácticas,
referencias) **no se guardan aquí** — solo nombres y el cargo/relación
que justifica su valor como referencia. Los contactos completos quedan
únicamente en el Google Drive privado del profesor. Tampoco se guardan
aquí datos como número de pasaporte o dirección completa.
