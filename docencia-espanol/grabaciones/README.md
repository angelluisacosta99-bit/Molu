# Grabaciones de clases

Los audios y videos de las clases **no se suben a este repositorio**
(Git no es un buen lugar para archivos pesados: ralentiza el repo y
GitHub bloquea archivos de más de 100MB).

En su lugar:

1. Sube la grabación a Google Drive.
2. Añade aquí una línea con la fecha, el alumno/grupo y el enlace.
