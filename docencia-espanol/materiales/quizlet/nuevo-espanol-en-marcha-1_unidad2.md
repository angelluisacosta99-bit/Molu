## 2. Plural de los nombres (regla)

| Español | Ruso |
|---|---|
| singular + vocal → + s (un mapa → dos mapas) | к гласной прибавляем "-s" |
| singular + consonante → + es (un autobús → dos autobuses) | к согласной прибавляем "-es" |
| un hotel → dos hoteles | пример: отель / отели |
| un profesor → dos profesores | пример: преподаватель / преподаватели |
| una ciudad → dos ciudades | пример: город / города |

|---|---|

## 7. La hora

| Español | Ruso |
|---|---|
| ¿Qué hora es? | Который час? |
| Es la una | Час (01:00) |
| Son las dos / las tres... | Два часа / три часа... |
| ...en punto | ровно |
| y cinco | пять минут (после часа) |
| y diez | десять минут |

| y veinticinco | двадцать пять минут |

| menos veinte | без двадцати |
| menos cuarto | без четверти |
| menos diez | без десяти |
| menos cinco | без пяти |
