# Máster en Sistemas Inteligentes (Salamanca)

Apuntes, prácticas y trabajos del máster. Cuando empiecen las clases,
crea una subcarpeta por asignatura, por ejemplo:

```
master-sistemas-inteligentes/
├── aprendizaje-automatico/
├── procesamiento-lenguaje-natural/
├── becas-financiacion/
└── ...
```

Ver [`becas-financiacion/becas-y-ayudas.md`](becas-financiacion/becas-y-ayudas.md)
para el listado de becas y ayudas investigadas para financiar el máster
(plazos, requisitos, qué aplica y qué no según el perfil del alumno).
