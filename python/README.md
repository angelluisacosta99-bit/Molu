# Python

Aprendizaje de Python por cuenta propia.

## Subcarpetas

- `ejercicios/` — prácticas cortas mientras aprendes conceptos nuevos
  (bucles, funciones, clases...). Un archivo o carpeta por ejercicio.
- `proyectos/` — cosas más elaboradas y con varios archivos (por ejemplo,
  la integración con la API de OpenAI que comentamos antes).

## Buenas prácticas al añadir un proyecto en `proyectos/`

1. Crea una carpeta con el nombre del proyecto (`kebab-case`).
2. Dentro, un `README.md` corto explicando qué hace y cómo ejecutarlo.
3. Si usas librerías externas, incluye un `requirements.txt`.
4. El entorno virtual (`venv/`) nunca se sube — ya está en `.gitignore`.
