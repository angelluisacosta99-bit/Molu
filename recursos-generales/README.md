# Recursos generales

Notas y recursos que no encajan en ninguna otra carpeta de primer nivel
del repositorio.

## Subcarpetas

- `herramientas-ia/` — registro de novedades de herramientas de IA
  (funciones de Claude Code, skills, plugins, conectores MCP,
  herramientas de terceros) relevantes para el trabajo de este
  repositorio. Ver `herramientas-ia/novedades.md` y la sección
  `## Radar de herramientas de IA` en `CLAUDE.md`.

## Archivos sueltos

- `notas-sueltas.md` — espacio temporal para apuntes o ideas que aún no
  encajan en ninguna otra carpeta. Cuando un tema crece lo suficiente,
  se mueve a su propia carpeta.
