# Telecomunicaciones

Notas, apuntes y proyectos relacionados con la ingeniería en
telecomunicaciones, con foco en la especialidad de transporte ferroviario
(sistemas de comunicación, señalización, redes de control, etc.).

## Subcarpetas

- `ferroviario/` — todo lo específico del ámbito ferroviario: normativa,
  proyectos, apuntes técnicos.

Cuando surjan otras ramas de telecomunicaciones que no sean ferroviarias,
crea una nueva subcarpeta al mismo nivel que `ferroviario/` con un nombre
descriptivo.
