# Traducción

Encargos y proyectos de traducción.

## Organización sugerida

Una subcarpeta por encargo/cliente dentro de `proyectos/`, por ejemplo:

```
proyectos/
├── 2026-02_cliente-x_manual-tecnico/
│   ├── original.pdf
│   └── traduccion.docx
└── 2026-03_cliente-y_contrato/
```

Usa el formato `AAAA-MM_cliente_tema` para poder ordenar cronológicamente
de un vistazo.
